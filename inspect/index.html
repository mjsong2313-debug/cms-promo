01왜 놓치나

사람 눈에는 정상인 사이트가, 로봇에게는 아닐 수 있습니다

브라우저에서 열면 메인도 뜨고 기사도 뜹니다. 그래서 아무도 모릅니다. 문제는 사람이 아니라 검색 로봇이 지나가는 길에서 일어납니다.

대표님이 보는 화면 · 정상

메인·최신 기사·관리자 화면이 모두 열립니다

눈으로 보는 한 이상이 없습니다. 카톡방에 던진 링크도 잘 열립니다.

검색 로봇이 받는 응답 · 예시

외부엔진을 사이트 앞에 연결하는 방식입니다. 기존 CMS와 관리자 화면, 디자인은 그대로 둡니다. 적용 가능 여부는 진단 뒤에 확인합니다.

임대·구독형 CMS

화면만 멀쩡하면 정상으로 보입니다

임대형 CMS는 서버 설정을 고객사가 직접 고치기 어렵고, 로봇 관점의 점검 결과는 따로 받기 어렵습니다. 진단은 특정 업체의 책임을 따지지 않고 공개 주소에서 확인되는 사실만 적습니다.

일반 검색은 되는데 Google News는 왜 안 될까

1 · 읽을 수 있는가

robots.txt, 경로 차단, meta robots, 방화벽·CDN 응답, 서버 오류, HTTPS 인증서.

2 · 기사로 인식되는가

canonical, JSON-LD, 제목·게시일·작성자, 없는 주소의 404와 Soft 404.

3 · 새 기사를 알릴 수 있는가

뉴스 사이트맵·RSS의 유효성·최신성, 삭제 기사 잔존, 신문법 표시.

구글이 실제로 본 결과는 Search Console에서만 확인됩니다. 진단은 그 도구를 대신하지 않고 원인 후보를 찾는 일입니다. 한 시점의 표본 확인이며 구글 뉴스 등재와 노출을 보장하지 않습니다.

05자주 묻는 질문

먼저 궁금해하시는 것

진단하면 구글 뉴스에 등재되나요? 순위가 오르나요?
아니요. 현재 사용하고 있는 홈페이지 CMS의 문제점을 진단·확인하는 단계입니다.
CMS를 바꿔야 하나요?
바꾸지 않는 것이 출발점입니다. 기존 CMS를 두고, 진단에서 나온 문제 가운데 외부엔진 연결로 처리할 수 있는 것만 제안합니다.
검사 시 우리 사이트에 문제가 발생하나요?
일반 방문자처럼 GET 요청만 보냅니다. 요청 수 상한과 요청 간격을 적용합니다. 점검 프로그램의 기본값은 요청 300건 상한, 요청 사이 0.7초 간격이며, 실제 값은 신청 때 안내합니다. 신청 접수시 사이트 주소 동의 절차를 걸쳐 정밀 검사를 진행 합니다.
진단은 얼마나 걸리나요?
보통 10분 안팎입니다. 사이트 응답이 느리거나 오류가 잦으면 더 걸릴 수 있습니다.
진단만 받고 끝내도 되나요?
네. 진단은 읽기만 하며 사이트를 건드리지 않습니다. 문제 해결과 지속 관제는 별도 단계이고, 원하실 때만 이어 갑니다.
구글 서치콘솔과 뭐가 다른가요?
서치콘솔은 구글이 본 결과를 알려 줍니다. 이 서비스는 홈페이지 겉모습을 진단해 원인 후보를 찾습니다. 서로 대신하는 관계가 아니어서 함께 쓰시길 권합니다. 신청서 접수시 정밀 검사를 진행하여 완벽한 점검이 이루어 집니다. (검사 총 49개 항목)
