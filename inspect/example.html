실패 — 먼저 고칠 항목 (25건)

A-02 · 기사·이미지·CSS·JS 경로 차단 여부 치명

기사 주소 8건이 robots.txt로 막혀 구글봇이 읽지 못합니다.

  • /news/view.html?idxno=5
  • /news/view.html?idxno=1001
  • /news/view.html?idxno=1002
  • /news/view.html?idxno=1003
  • /news/view.html?idxno=1004
  • …외 3건

고치는 방법: robots 규칙 변경은 고객 서버 설정: 차단 경로와 수정 예시를 안내 (교정 방식: 안내서)

A-08 · HTTPS 인증서 치명

사이트가 HTTPS가 아닌 http로 열립니다. 인증서가 없거나 https로 연결되지 않습니다.

고치는 방법: 인증서 갱신 절차 안내(만료 임박 알림은 관제가 수행) (교정 방식: 안내서)

B-02 · canonical ↔ 요청 URL 일치 치명

canonical이 다른 기사 번호나 홈을 가리키는 기사가 1건 있습니다(표본 4건).

  • http://시험일보(가상)/news/view.html?idxno=1003 → canonical http://시험일보(가상)/news/view.html?idxno=1999 (기사 번호 1003≠1999)

고치는 방법: 식별자 불일치 응답을 404로 전환(기본은 관찰 모드, 승인 후 반영) (교정 방식: 자동)

C-01 · 없는 주소 요청 시 404 치명

존재하지 않는 주소 3건 중 3건이 404/410이 아닌 응답을 돌려줍니다.

  • http://시험일보(가상)/__edgeaudit_nf_1__ → 없는 주소인데 200 응답(Soft 404)
  • http://시험일보(가상)/news/__edgeaudit_nf_2__.html → 없는 주소인데 200 응답(Soft 404)
  • http://시험일보(가상)/news/view.html?idxno=99999 → 없는 주소인데 200 응답(Soft 404)

고치는 방법: 없는 주소의 200 응답을 404로 정정 (교정 방식: 자동)

C-02 · 삭제 기사의 사이트맵·RSS 잔존 치명

사이트맵·RSS에 오른 주소 2건 중 1건이 삭제됐거나 오류 문구가 보이는 페이지입니다.

  • [사이트맵] http://시험일보(가상)/news/view.html?idxno=5 → HTTP 200 존재하지 않는

고치는 방법: 사이트맵·RSS에서 오류 URL 제외 (교정 방식: 자동)

C-03 · 200 응답 + 오류 문구(Soft 404) 치명

200 응답인데 오류 안내로 보이는 페이지(Soft 404)가 4건 있습니다.

  • http://시험일보(가상)/news/view.html?idxno=5 → 200 응답인데 '존재하지 않는' 문구
  • http://시험일보(가상)/__edgeaudit_nf_1__ → 없는 주소인데 200
  • http://시험일보(가상)/news/__edgeaudit_nf_2__.html → 없는 주소인데 200
  • http://시험일보(가상)/news/view.html?idxno=99999 → 없는 주소인데 200

고치는 방법: 200+오류 문구 응답을 404로 정정(문구 기준은 고객사별 설정) (교정 방식: 자동)

D-01 · JSON-LD가 서버 HTML에 존재 치명

서버가 보낸 HTML에 JSON-LD가 없는 기사가 있습니다(스크립트로 나중에 주입되면 구글이 놓칠 수 있음): 표본 7건 중 3건.

  • http://시험일보(가상)/news/view.html?idxno=1004
  • http://시험일보(가상)/news/view.html?idxno=1005

고치는 방법: 서버 HTML에 JSON-LD 삽입 (교정 방식: 자동)

D-03 · JSON-LD 문법·중복 치명

JSON-LD 문법 오류가 있는 기사가 2건 있습니다. 구글이 구조화 데이터를 읽지 못합니다.

  • http://시험일보(가상)/news/view.html?idxno=1003 → JSON 문법 오류 1개
  • http://시험일보(가상)/news/view.html?idxno=1006 → JSON 문법 오류 1개

고치는 방법: 중복 블록 정리(이중 삽입 방지) (교정 방식: 자동)

D-05 · 게시일·수정일 형식 치명

게시일·수정일이 없거나 형식이 맞지 않는 기사가 2건 있습니다(표본 2건).

  • http://시험일보(가상)/news/view.html?idxno=1007 → datePublished '2026-10-02 22:49:40'가 시간대를 포함한 ISO 8601이 아님

고치는 방법: 날짜를 ISO 8601·시간대 포함 형식으로 변환(값 자체는 바꾸지 않음) (교정 방식: 자동)

D-07 · image 존재·접근성 치명

  • http://시험일보(가상)/news/view.html?idxno=1007 → 이미지 http://시험일보(가상)/img/bad.jpg: HTTP 404

고치는 방법: image가 없으면 본문 대표 이미지에서 채움 (교정 방식: 자동)

E-01 · 뉴스 사이트맵 존재·선언 치명

  • http://시험일보(가상)/news/view.html?idxno=1007 → 작성자 '관리자'

고치는 방법: 기자 프로필 데이터와 매칭해 author 보정(매칭 실패 시 건드리지 않음) (교정 방식: 자동)

RSS(또는 Atom) 피드를 찾지 못했습니다. 네이버·구글 모두 사이트맵을 우선하지만 RSS는 보조 수집 경로입니다.

I-05 · 윤리강령·편집규약 게시 중요

홈·회사소개에서 윤리강령·편집규약 링크를 찾지 못했습니다.

  • 반자동 점검: 링크 유무만 봅니다. 게시된 내용이 실제 강령인지는 사람이 확인해야 합니다.

통과

통과한 항목

  • A-04 meta robots·X-Robots-Tag — 홈과 기사 7건 모두 meta robots·X-Robots-Tag에 noindex가 없습니다.
  • A-06 방화벽·CDN 차단 응답 — 받아 본 12건의 응답에서 차단 응답의 흔적(403·429, 차단 안내 문구)이 없었습니다.
  • A-07 서버 오류(5xx)·시간 초과 — 받아 본 12건 모두 5xx 오류·시간 초과가 없었습니다(일회성 측정).
  • A-09 HTTP→HTTPS·www 단일화 — http/https·www 변형 1개가 모두 하나의 대표 주소(http://시험일보(가상)/)로 모입니다.
  • B-05 canonical 대상 URL 상태 — canonical 대상 주소 4건이 모두 200이며 이동·noindex가 없습니다.
  • B-08 리디렉션 체인·루프 — 받아 본 주소들에 이동 체인이 1단계를 넘는 경우나 루프가 없습니다.
  • D-04 headline ↔ 화면 제목 일치 — 표본 기사 2건 모두 headline이 화면 제목과 일치합니다.
  • D-11 publisher 정보 일관성 — 표본 기사 2건의 publisher가 '시험일보'로 일관되고 로고가 있습니다.
  • F-02 제목·게시시간 탐지 가능 위치 — 표본 기사 7건 모두 제목과 게시시간을 기계가 읽을 수 있는 위치에 두고 있습니다.
  • F-03 title·h1·기사 제목 일치 — 표본 기사 7건 모두 title·h1이 일치하고 h1이 1개입니다.
  • F-09 언어·문자셋 선언 — 점검한 8개 페이지 모두 언어(lang)와 문자셋이 선언되어 있습니다.
  • G-05 이미지 깨짐 비율 — 확인한 이미지 1건 모두 정상으로 열립니다.
  • I-04 기사 내 기자명·연락처 표기 — 표본 기사 7건 모두 기자명과 이메일 연락처가 표기되어 있습니다.
  • I-06 정정·반론 보도 영역 — 기사 하단 등에 정정·반론 관련 안내 문구가 있습니다.

확인 못 한 항목

점검하지 못했거나 사람이 확인할 항목

  • A-05 봇 이름별 응답 차이 미실시 — 검색봇 이름으로 요청해 보는 시험은 동의한 사이트에서만 하도록 기본 꺼져 있습니다(-simulate-bots로 켬).
  • E-02 기간·건수 한도 미실시 — 뉴스 사이트맵이 없어 점검하지 못했습니다(E-01 참조).
  • E-03 필수 태그 미실시 — 뉴스 사이트맵이 없어 점검하지 못했습니다(E-01 참조).
  • J-01 혼합 콘텐츠 해당없음 — 사이트가 https가 아니어서 혼합 콘텐츠 점검 대상이 아닙니다(A-08 참조).
  • J-04 도메인 만료일 미실시 — 도메인 만료일 조회(RDAP)를 끄고 실행했습니다.
  • K-01 서치어드바이저 등록·소유확인 수동확인 — 서치어드바이저 등록·소유확인은 로그인해야 볼 수 있어 자동으로 확인할 수 없습니다. 담당자가 서치어드바이저 화면에서 직접 확인하세요.

이 점검의 한계

  • 이 점검은 공개된 주소에 일반 GET 요청만 보내는 외부 점검이며, 한 시점의 표본(기사 몇 건)만 봅니다. 사이트 전체의 상태를 보증하지 않습니다.
  • 점수는 점검항목정의서의 자체 산식(치명 3·중요 2·권고 1, 경고는 절반 인정)이며 구글·네이버의 색인·노출 순위를 예측하지 않습니다.
  • 구조화 데이터(JSON-LD)는 구글이 뉴스 노출의 필수 조건으로 요구하지 않습니다. 이 항목들은 구글 공식 권고와 업계 관행에 근거한 점검입니다.
  • 봇 이름 흉내(-simulate-bots)는 기본 꺼져 있고, 켜도 실제 검색봇의 IP 기준 차단은 재현하지 못합니다.
  • EUC-KR 등 UTF-8이 아닌 페이지는 한글 문구 판정이 부정확할 수 있습니다.
  • 화면 렌더링이 필요한 항목(가로 스크롤, 스크립트로 채워지는 본문 등)과 로그인이 필요한 항목(서치어드바이저, Search Console)은 확인하지 못합니다.
