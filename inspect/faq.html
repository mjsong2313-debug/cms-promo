자주 묻는 질문

일반 검색은 되는데 Google News는 왜 안 될까요?

일반 검색과 구글 뉴스는 서로 다릅니다. 같은 문제로 판단해서는 안 됩니다. 진단은 구글뉴스봇이 기사를 읽을 때 걸릴 수 있는 접근 차단, 기사 구조화 데이터, 뉴스 사이트맵·RSS, 오류 기사 처리 같은 기술 상태를 공개 주소에서 확인되는 범위로 봅니다. 구글이 실제로 어떻게 판단했는지는 Search Console과 Google News 지원을 통해서만 확인할 수 있습니다.

‘구글뉴스봇’이 정확히 무엇인가요?

구글 뉴스와 관련된 구글의 크롤러를 편의상 줄여 부르는 말입니다. 기술 보고서에는 Googlebot, Google News, Search Console 같은 구글의 공식 명칭을 씁니다.

진단하면 구글 뉴스에 등재되나요? 순위가 오르나요?

아니요. 현재 사용하고 있는 홈페이지 CMS의 문제점을 진단·확인하는 단계입니다.

CMS를 바꿔야 하나요?

바꾸지 않는 것이 출발점입니다. 기존 CMS를 그대로 두고, 진단에서 나온 문제 가운데 외부엔진 연결로 처리할 수 있는 것만 제안합니다. 실제로 적용할 수 있는지는 CMS·서버·방화벽(WAF)·Search Console 상태를 보고 진단 뒤에 확인합니다.

검사 시 우리 사이트에 문제가 발생하나요?

일반 방문자처럼 GET 요청만 보냅니다. 요청 수 상한과 요청 간격을 적용합니다. 점검 프로그램의 기본값은 요청 300건 상한, 요청 사이 0.7초 간격입니다. 실제 점검에 적용하는 값은 신청 때 안내합니다. 신청 접수시 사이트 주소 동의 절차를 걸쳐 정밀 검사를 진행 합니다.

진단하면 비용이 환불되나요?

진단 후 해결 계약을 체결하시면 진단비를 전액 환불합니다. 해결 계약을 하지 않으시면 진단비는 환불되지 않습니다. 환불 기한과 방식은 계약서에 따릅니다.

진단은 얼마나 걸리나요?

보통 10분 안팎입니다. 요청 수 상한 250건, 요청 간격 1초로 계산하면 응답이 빠른 사이트는 약 4분, 건당 응답이 2.4초면 약 10분입니다. 사이트 응답이 느리거나 오류가 잦으면 더 걸릴 수 있습니다.

렌더링·코어 웹 바이탈·방화벽·CDN 문제도 진단하나요?

엔진 자동 진단만으로는 볼 수 없는 항목입니다. 진단 신청 때 Search Console 열람 권한, 방화벽·CDN 설정과 접속 기록, 코어 웹 바이탈·렌더링 자료를 제공해 주시면 담당자가 함께 확인해 보고서에 ‘제공 자료 기반 확인’으로 따로 적습니다. 자료가 없으면 ‘미확인’입니다.

진단만 받고 끝내도 되나요?

네. 진단은 읽기만 하며 사이트를 건드리지 않습니다. 문제 해결과 지속 관제는 진단과 별도 단계이고, 원하실 때만 이어 갑니다.

문제 해결은 어떻게 진행되고 얼마인가요?

진단 보고서에서 나온 문제를 보고 사이트별로 견적을 드립니다. 모든 사이트에 같은 코드를 쓰지 않고 필요한 기능만 연결합니다. 이 단계의 실제 사이트 적용 절차와 견적 기준은 정리 중이라 가격을 미리 정해 두지 않았습니다.

구글 서치콘솔과 뭐가 다른가요?

서치콘솔은 구글이 본 결과를 알려 줍니다. 이 서비스는 홈페이지 겉모습을 진단해 원인 후보를 찾습니다. 서로 대신하는 관계가 아니어서 함께 쓰시길 권합니다. 신청서 접수시 정밀 검사를 진행하여 완벽한 점검이 이루어 집니다. (검사 총 49개 항목)

어떤 사이트를 진단하나요?

신문사 홈페이지가 중심입니다. 신문사는 기본 49항목입니다. 그 밖의 업종은 전용 규칙을 아직 정하지 않아, 진단할 수 있는 범위를 신청 때 먼저 안내합니다. 본인 소유이거나 점검 권한이 있는 사이트만 진단합니다.

네이버 플레이스·구글 비즈니스 프로필도 확인하나요?

아니요. 외부 서비스에 올린 정보와의 대조는 하지 않고, 사이트 안의 전화·주소 표기가 서로 맞는지만 봅니다. 프로필 일치 여부는 담당자가 직접 확인해야 하는 항목으로 보고서에 안내합니다.

AI 검색 노출도 진단하나요?

현재 기본 단계에서는 AI 크롤러 허용 여부 등 기술 항목만 봅니다. 인용·노출 여부는 진단하지 않습니다. 이 영역은 제작 확정 단계이고 효과는 검증 중입니다.

접근성·보안 헤더·키워드 같은 선택 점검도 하나요?

점검 프로그램에 옵션으로 들어 있습니다. 접근성은 html lang·페이지 제목·이미지 대체 텍스트·제목 구조·입력칸 이름표·이름 없는 링크/버튼 6가지를 HTML에서만 확인하며 색 대비·키보드 이동·화면 읽기 프로그램 동작은 보지 못하고 법령 충족 여부도 판단하지 않습니다. 보안 헤더는 응답 헤더 설정 여부만 보고 “권고 보안 헤더 미설정”으로 알려 줄 뿐 보안 취약점이 있다고 판정하지 않습니다. 제목 목차와 키워드는 단순 어절 기준(조사 포함) 참고용 데이터이며 점수에 넣지 않습니다. 세 가지 모두 직접 만든 가상 사이트에서만 시험했고, 옵션을 켜면 종합 점수가 켜지 않은 결과와 달라져 서로 비교할 수 없습니다.

진단 결과는 누가 보나요?

의뢰하신 분에게만 전달합니다. 다른 사이트의 진단 결과를 공개하지 않습니다.
