진행 방식

진행 방식

진단 → 보고서 → (선택) 문제 해결 → (선택) 지속 관제 순서입니다. 진단만 받고 끝내셔도 됩니다. 진단 소요 시간: 보통 10분 안팎(사이트 응답 속도에 따라 달라집니다).

  1. 1

    진단 신청

    진단할 홈페이지 주소와 담당자 연락처를 보냅니다. 본인 소유이거나 점검 권한이 있는 사이트인지 확인합니다. 권한 확인이 안 되는 사이트는 진단하지 않습니다.

  2. 2

    진단 실행

    읽기 전용으로 진단합니다. 일반 GET 요청만 보내고, 요청 수 상한과 요청 간격을 적용합니다.

  3. 3

    보고서 전달

    한국어 보고서(audit_report.md)와 항목별 판정 파일(JSON·CSV)을 의뢰하신 분에게만 전달합니다. 귀사 홈페이지에서 실제로 확인된 문제를 근거와 함께 적습니다.

  4. 4

    문제 해결 견적 (선택)

    진단에서 나온 문제 가운데 외부엔진 연결로 처리할 수 있는 것을 가려 견적을 드립니다. 기존 CMS를 바꾸지 않는 방향이며, CMS·서버·방화벽(WAF)·Search Console 상태를 먼저 확인한 뒤 필요한 기능만 연결합니다. 적용 가능 여부는 진단 뒤에 확인합니다. 견적서로 범위와 금액을 확인하고 서비스 계약서를 체결한 뒤에 작업을 시작합니다.

  5. 5

    지속 관제 (선택 · 제작 확정, 제공 전)

    해결 이후의 변경 감지와 이상 징후 확인을 월 단위로 이어 가는 단계입니다. 아직 서비스로 제공하지 않으며, 제공 시점과 조건이 정해지면 이 페이지에 알립니다.

의뢰인 제공 자료로 확인하는 것

진단을 신청할 때 Search Console 열람 권한, 방화벽(WAF)·CDN 설정과 접속 기록, 코어 웹 바이탈·화면 렌더링 자료를 제공해 주시면 담당자가 엔진 진단과 별도로 확인합니다. 렌더링 결과, 코어 웹 바이탈, 구글 IP 기준 방화벽 차단, CDN 오류 캐시가 여기에 해당합니다. 보고서에는 ‘제공 자료 기반 확인’으로 따로 구분해 적고, 자료가 없으면 ‘미확인’으로 남깁니다. 제공 자료는 진단 목적으로만 쓰고 제3자에게 주지 않으며, 정해진 보관 기간이 지나면 폐기합니다. 비밀번호는 받지 않습니다.

진단이 확인하지 못하는 것

  • Search Console·네이버 서치어드바이저 등록 상태 (로그인이 필요합니다)
  • 엔진 자동 진단만으로는 브라우저가 실제로 그리는 화면, 코어 웹 바이탈, 구글 IP 기준 방화벽 차단, CDN 오류 캐시를 볼 수 없습니다. 아래 ‘의뢰인 제공 자료로 확인하는 것’을 보세요.
  • 사이트에 적힌 신문법 표시값이 법에 맞는지 (표시 유무만 확인합니다)
  • 네이버 플레이스·구글 비즈니스 프로필과 사이트 정보가 일치하는지, 사업자등록번호가 실제로 등록된 번호인지 (홈페이지 안의 표기만 봅니다)
  • 한 시점 이후의 변화 (진단은 실행한 순간의 표본입니다)
