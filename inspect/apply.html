진단은 본인 소유이거나 점검 권한이 있는 사이트만 합니다. 신문사 홈페이지를 우선으로 받습니다. 아래 항목을 입력해 주세요.

선착순 10개사 무료 진단 접수 중. 아래 항목을 입력해 신청해 주세요.

http 또는 https 주소. localhost·내부망 주소와 IP 직접 입력은 받지 않습니다.

추가 확인용 자료 제공 선택

엔진이 자동으로 볼 수 없는 항목은 아래 자료를 제공해 주시면 담당자가 함께 확인해 보고서에 따로 적습니다. 자료를 주지 않으면 해당 항목은 ‘미확인’으로 남습니다. 접속 기록은 필요한 기간만, 방문자 IP는 가려서 보내 주시면 가장 좋습니다. 제공 자료는 진단 목적으로만 쓰고 의뢰하신 분께만 결과를 드립니다. 비밀번호는 보내지 마세요.
